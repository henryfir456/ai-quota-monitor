# DEPLOYMENT｜正式交付政策

## 預設：未授權
建立新專案時本文件只有範本，不代表授權 push、merge、release、deploy 或變更正式資料。不得因其他專案（例如便當系統）有預設自動部署，就把其授權套用到這裡。

## 專案設定（建立後必填）
- 應用與正式環境：UNKNOWN
- 正式前端／後端部署對象：UNKNOWN
- 自動合併授權條件：未授權
- 正式部署授權條件：未授權
- 資料修復或 migration 授權：未授權
- 驗證命令與 smoke check：UNKNOWN
- 回滾程序：UNKNOWN

## 交付 Gate
開發完成→測試證據→獨立審閱→核對當前 head SHA→核對授權→依政策合併→部署對應正式環境→有界驗收。
任何一步缺證據，交付狀態應明確記為 WAITING_FOR_DELIVERY / NOT VERIFIED，不得宣稱已正式完成。

## 特例
既有專案若已明確記錄、經使用者批准的「特定 backend 修改預設合併 main 並正式部署」政策，須在該專案此文件詳細定義邊界；不能覆蓋正式資料、Secrets、權限升級等更高風險操作的額外授權要求。
