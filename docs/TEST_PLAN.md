# TEST_PLAN｜驗證計畫

| 領域 | 驗證方法 | 狀態 | 證據 |
| --- | --- | --- | --- |
| 單元測試 | 依 REPO_FACTS 宣告 | NOT RUN | |
| 整合測試 | 依需求界定 | NOT RUN | |
| 靜態分析及建置 | 依實際技術棧 | NOT RUN | |
| 版本與繁中翻譯一致性 | 發布前檢查 | NOT VERIFIED | |
| 實機／真實登入／正式雲端 | 需外部或人工證據 | NOT VERIFIED | |
| 部署後 smoke test | 授權且部署後才進行 | NOT RUN | |

驗證結果只可為 PASS、FAIL、NOT RUN、NOT VERIFIED。未執行的檢查不得因 CI 其他項成功就改標 PASS。
